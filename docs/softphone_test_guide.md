# Softphone Testing Guide (Human-in-the-Loop)

이 문서는 VBGW 시스템을 Zoiper, Linphone 등의 소프트폰을 이용하여 수동으로 검증하는 방법을 안내합니다.
이 테스트는 STT, NLU, TTS가 결합된 엔드투엔드 AI 음성 품질을 사람이 직접 듣고 평가하기 위해 수행됩니다.

## 1. 사전 준비

### 1.1. 소프트폰 설치
- **Zoiper** (추천) 또는 **Linphone**을 PC 또는 모바일 기기에 설치합니다.

### 1.2. 환경 설정
- **SIP Server (Domain)**: `<VBGW_IP>:5060` (예: `127.0.0.1:5060` 또는 Envoy LoadBalancer IP)
- **Username / Auth Name**: `test_user`
- **Password**: `test_pass`
- **Transport**: `UDP` (또는 VBGW 설정에 따라 `TLS`)
- **Audio Codec**: `G.711 PCMU` 또는 `PCMA` (8kHz) 만 활성화합니다. (G.722, Opus 등은 비활성화)

## 2. 테스트 시나리오

### 2.1. 인바운드 콜 연결 테스트
1. 소프트폰에서 임의의 번호(예: `1004`)로 발신합니다.
2. VBGW가 전화를 수신(200 OK)하는지 확인합니다.
3. 통화가 연결되면 AI의 **Greeting(인사말) TTS**가 정상적으로 들리는지 확인합니다.
   - *검증 포인트: 오디오 지연(Latency), 끊김 현상(Jitter), 음질*

### 2.2. VAD 및 STT 인식 테스트
1. 인사말이 끝난 후 자연스럽게 말을 걸어봅니다. (예: "안녕하세요, 예약하려고 하는데요.")
2. 시스템이 사용자의 음성 종료(VAD)를 정확히 감지하는지 확인합니다.
3. AI 서버가 응답을 생성하여 다시 오디오를 스트리밍해주는지 확인합니다.
   - *검증 포인트: 말을 끊었을 때 STT가 얼마나 빨리 인식되는가?*

### 2.3. Barge-in (끼어들기) 테스트
1. AI가 길게 대답하는 도중에 사용자가 말을 시작해봅니다. (예: "아니요, 그게 아니라요.")
2. AI의 발화가 즉각적으로 중단되고(Barge-in), 사용자의 말을 다시 인식하는지 확인합니다.
   - *검증 포인트: RingBuffer 플러시 및 TTS 오디오 재생 중지 동작 확인*

### 2.4. 예외 상황 테스트
1. 아무 말도 하지 않고 가만히 있을 때의 타임아웃/Filler 동작 확인.
2. 통화 중 소프트폰에서 직접 전화를 끊었을 때 서버 자원(PJSIP, gRPC 세션)이 안전하게 해제되는지 VBGW 로그 확인.
